# Прокси Рубеж

> 57 рабочих MTProxy для Telegram — живой список с проверкой пинга.

[![Сайт](https://img.shields.io/badge/сайт-retrobusinesssieve.github.io-9d2588)](https://retrobusinesssieve.github.io/)
[![Канал](https://img.shields.io/badge/Telegram-@mtprxtg-2aabee)](https://t.me/mtprxtg)

## Что внутри

- `57` проверенных прокси-серверов MTProxy: наши серверы @mtprxtg + отобранные публичные;
- проверка доступности прямо на странице (кнопка «Проверить все»);
- подключение в один клик — Telegram открывается сам;
- сайт устанавливается на телефон как приложение (PWA).

**Открыть список:** [https://retrobusinesssieve.github.io/](https://retrobusinesssieve.github.io/)

## Подключение вручную

Telegram → Настройки → Данные и память → Прокси → MTProto — или просто нажмите «Подключить» на сайте.
